# Clean Windows distribution

`scripts/build-installer.ps1` builds the installed local client, with embedded production UI and custom icons. Recipients do not need Node, Rust, Python, MSVC, a development server, a publisher PC or a signing private key.

The normal installer includes Microsoft's verified small WebView2 bootstrapper and keeps the canonical `UnknownAlt-Setup-X.Y.Z.exe` filename for signed updates. For a self-contained first installation on native Windows x64, pass `-OfflineRuntime`; the full Microsoft Evergreen Standalone runtime is embedded in `UnknownAlt-Setup-X.Y.Z-Windows-x64.exe`. Missing WebView2 is installed before any app files are replaced. Full offline installers are separate from canonical update assets and can exceed the update channel's 200 MB limit.

Prepare a fresh source-only staging folder. Never copy an installed data folder, profile, `location.json`, database, vault key, browser directory, log, cache, `.env`, signing key or developer-tool installation into it. The installer has an explicit five-file payload: application executable, custom icon, MIT license, rebranding notes and the verified public Microsoft runtime prerequisite. Installer/uninstaller metadata is generated by Inno Setup.

For privacy, compile from a neutral build path with a neutral Cargo registry/target directory. Rust dependencies can contain source locations and native C libraries can contain `__FILE__` assertion paths; stripping debug symbols alone does not remove them. Use `--remap-path-prefix` for Rust build/source/home locations, and build native dependencies anew from the neutral registry rather than reusing artifacts compiled under a personal profile. Validate the final extracted executable and text for personal paths and identifiers.

Ordinary launches generate fresh database/vault keys and store accounts, settings and WebView sessions under the current user's `%LOCALAPPDATA%\UnknownAlt`. Tauri window state is under `%APPDATA%\com.unknownalt.desktop`. Nothing is seeded from the publisher's profile. Existing installations retain their own data on upgrade; the installer does not reset other people's accounts.

Explicit `UNKNOWNALT_DATA_DIR`/legacy test overrides create isolated test instances: Tauri directories and singleton identity are scoped to that fixture, and global Roblox/Discord integration side effects are suppressed. Normal installations without a test override keep their original integration behavior and identity. An isolated empty data-directory test is useful for package smoke checks, but it must not be described as a separate Windows-account test. A true profile test requires another Windows user or a clean Windows VM.

The public updater contains the owned GitHub release channel and pinned public verification key. It needs no sign-in or embedded credentials and never loads old private-update tokens. Keep the signing private key outside source, CI and distribution. Publish canonical installer/manifest/signature assets as described in `UPDATES.md`; the full offline bootstrap installer is separate.
