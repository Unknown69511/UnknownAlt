# Unknown alt app privacy notice

Unknown alt is an independent utility for Windows. It stores account sessions,
preferences, client history and backups on your computer. Windows protects the
database key with Data Protection API (DPAPI). You can additionally protect the
account vault with a master password. Use the app's Data settings to manage
backups and cache and the Accounts view to remove accounts.

Roblox sign-in, account and game features communicate with Roblox. Connected
Google or Apple sign-in is available when selected during Roblox sign-in. The
app uses the selected Roblox session when you request account actions. Roblox,
Google and Apple apply their respective privacy policies to their services.

The Windows EXE checks GitHub for signed Unknown alt updates. The Updates page
loads public release notes from GitHub and public Roblox notices from DevForum.
These requests do not include saved Roblox accounts or sessions. The Microsoft
Store edition uses the Store for package updates. The app does not send usage
telemetry to the Unknown alt maintainer.

Optional Discord notifications send the configured event details to the Discord
webhook you supply. Optional Rich Presence shares the game or managed-client
status you choose through your local Discord client. Review these settings
before enabling either integration.

Support is available through the [Unknown alt project](https://github.com/Unknown69511/UnknownAlt/issues).
Share only information needed to describe the issue. Keep account credentials,
session files and backups private.
